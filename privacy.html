Privacy Policy

Last updated: May 26, 2026

LootSnag stores only what it needs to function. This page explains exactly what that is, why we store it, and how you can get it deleted.

What we store

Server data — stored when LootSnag is added to a server:

DataWhy
Server (Guild) IDIdentifies which server the settings belong to
Channel IDsKnows where to post free game and deal alerts
Deal thresholdFilters deals by minimum discount percentage
Currency preferenceShows prices in INR or USD
Enabled storesFilters alerts to selected stores only

User data — stored when you use commands like /wishlist, /currency, or /settings:

DataWhy
Discord User IDLinks your preferences and wishlist to your account
Currency preferenceShows prices in your preferred currency
Alert methodControls whether alerts go to DM, channel, or both
Wishlist entriesGame IDs and titles you want to track for deals

Operational data — stored to prevent duplicate posts:

DataWhy
Deal IDs, titles, pricesTracks what's already been posted so the same deal isn't sent twice
Message IDsAllows editing existing posts when deal info changes

What we do not store

  • Your username, display name, or avatar
  • Any message content from your server
  • Your IP address or location
  • Any payment or financial information
  • Data from channels the bot is not configured to use

How data is used

All stored data is used exclusively to operate LootSnag's features. We do not sell, share, or use your data for advertising, analytics, or any purpose outside of running the bot.

Where data is stored

Data is stored in a MongoDB database hosted on MongoDB Atlas (cloud-hosted, US region). Operational deal records are automatically deleted after 30 days as part of a daily cleanup routine.

Third-party data sources

LootSnag fetches game and pricing data from the following external APIs. Your data is never sent to these services — they are read-only sources:

  • Epic Games Store API
  • Steam Store API
  • CheapShark API
  • RAWG API (game images)
  • Frankfurter API (exchange rates)

Deleting your data

Server data is automatically deleted when LootSnag is removed from your server.

User data and wishlist — to request deletion, contact us. We'll remove your data within 7 days.

Operational records are purged automatically on a daily schedule. No action needed from you.

Children's privacy

LootSnag does not knowingly collect data from anyone under the age of 13. If you believe this has happened, contact us and we'll delete the data immediately.

Changes to this policy

We may update this policy as the bot's features change. Significant changes will be announced through the support server.

Contact

For privacy requests or questions, reach us at madxdev@proton.me or through the support server linked in LootSnag's Discord profile.
